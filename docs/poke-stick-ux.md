# Проверка палкой — UX-фишка Опоры

## Суть

**Проверка палкой** — фирменный мягкий health-check в системе «Опора».

Это не токсичная мотивация, не контроль ради контроля и не попытка заставить пользователя «быть продуктивным». Это короткий дружеский сигнал:

> Эй, ты живой человек, а не сервер под нагрузкой.

## Зачем это нужно

У пользователя есть риск уходить в режим:

- «ещё одну задачку закрою»;
- «надо вывезти»;
- «потом отдохну»;
- «семья подождёт»;
- «здоровье потерпит».

Проверка палкой возвращает в базовые опоры:

- вода;
- еда;
- пауза;
- один фокус;
- семья;
- не принимать больших решений в красной зоне;
- не превращаться в камень.

## Тональность

Тон должен быть:

- с юмором;
- без стыда;
- без давления;
- коротко;
- по-человечески;
- немного абсурдно, но заботливо.

Нельзя:

- морализировать;
- стыдить;
- писать как корпоративный wellness-bot;
- давить продуктивностью;
- превращать уведомление в длинную лекцию.

## Основная формула

> *тык палкой*  
> Объект живой?  
> Вода, пауза, один фокус.  
> Не превращаемся в камень.

## Режимы

### 🟢 Green

Объект живой, местами даже функциональный.

Рекомендация:

- один главный фокус;
- не распыляться;
- записать расходы;
- не разгонять себя без причины.

Пример:

> 🟢 *тык палкой*  
> Живой. Процессор отвечает.  
> Один фокус, вода, без героизма.

### 🟡 Yellow

Квадратная голова, но процессор ещё отвечает.

Рекомендация:

- механические задачи;
- чай/вода;
- таймер 25 минут;
- никаких больших решений;
- снизить скорость.

Пример:

> 🟡 Проверка палкой.  
> Квадратная голова?  
> Вода. Пауза. Только механика.  
> Не строим империю на 7% заряда.

### 🔴 Red

Потыкали палкой — признаков продуктивности нет.

Рекомендация:

- еда;
- вода;
- тишина;
- не спорить;
- не покупать Гелик;
- не принимать решений;
- домой/сон/восстановление при возможности.

Пример:

> 🔴 *тык палкой*  
> Объект ворчит и просит чай.  
> Большие решения запрещены.  
> Еда, вода, тишина. Папа в энергосбережении.

## Cron-уведомления MVP

Локальные iOS-уведомления:

- 09:30 — утренний check-in;
- 13:30 — дневная проверка;
- 18:30 — переход домой;
- 22:00 — закрытие дня.

Тексты:

### 09:30

> *тык палкой* Живой? Вода, один фокус, без героизма.

### 13:30

> Квадратная голова? Пауза, вода, механические задачи.

### 18:30

> Домой без исчезновения. Назови состояние. Семья — не плата за успех.

### 22:00

> Не решаем всю жизнь. Закрываем день и не превращаемся в камень.

## Где использовать

- iOS local notifications;
- Telegram command `/nerve_status`;
- Telegram command `/poke`;
- Today screen;
- Operation screen;
- onboarding;
- empty states;
- error states, если ошибка не критическая.

## Продуктовая роль

Проверка палкой — это signature feature Опоры.

Она делает приложение живым, личным и не похожим на стандартные трекеры привычек.

Формула бренда:

> Опора — мягкая система самоконтроля с функцией регулярного тыканья палкой.

## Красная линия

Проверка палкой не должна становиться инструментом самодавления.

Если пользователь в красной зоне, приложение не должно говорить «соберись». Оно должно говорить:

> Снизь нагрузку. Ты не сервер. Ты человек.
